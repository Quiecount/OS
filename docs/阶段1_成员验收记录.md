## yu 的 map 判空引导练习（2026-11-19）

本人在虚拟机执行编译和加载，提供了拒绝日志；随后亲手修改并重新加载。
助手通过共享工作区核对源码和 fixed.log，确认：

- 初次编译命令遗漏 `-c`，本机链接器不识别 BPF ELF，未生成对象文件。这是编译/链接错误。
- 修正编译命令后，对未判空版本的加载得到 `VERIFIER_REJECTED`，
  明确拒绝行为 `R0 invalid mem access 'map_value_or_null'`。
- 实际修复为先初始化 `ret = 0`，仅在 `if (value)` 分支中执行 `ret = *value`，再返回 ret。
- 修复后本人执行加载，得到 `VERIFIER_ACCEPTED`；日志显示 `processed 11 insns`。
- 工作文件与两份日志位于本机 `build/stage1-practice/yu/`，被 Git 忽略。

本项属于助手提供错误样例和提示后的引导修复，已完成；尚不代表无教程独立复现。
当前仍待 ringbuf 探针与加载器的本人动手、独立重现及队友核验。
